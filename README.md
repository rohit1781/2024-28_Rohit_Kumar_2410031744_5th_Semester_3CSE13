## 📌 About the Internship

The internship focused on building a strong practical foundation in Machine Learning and Deep Learning using **TensorFlow**, applied to real-world computer-vision problems: image classification, on-device object detection, and product image search for mobile applications. It followed a structured, week-wise curriculum combining conceptual learning, hands-on labs, quizzes, and skill badges on the Google Developer Program platform, culminating in a Final Credential Validation.

**Organization:** EduSkills runs the AICTE–EduSkills Virtual Internship Program in association with the Ministry of Education and the **AICTE National Internship Portal**, in partnership with **Google for Developers** through the India Edu Program.

---

## 🎯 Objectives

- Build convolutional neural networks (CNNs) using TensorFlow, from first principles
- Integrate pretrained object detectors into mobile applications
- Train custom object-detection models with TensorFlow Lite & Model Maker
- Build a product image search feature using on-device object detection
- Detect objects in static images and live camera feeds
- Build backend integration for a product image search mobile app
- Build and improve custom image-classification models
- Integrate a custom image classifier into a working application

| Week | Module | Description |
